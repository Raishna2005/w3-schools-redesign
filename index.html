Pathways

Structured learning paths

Not sure what to learn next? Follow a curated path built around real job roles.

Front-end developer

Build everything users see and interact with. Start with HTML, add styling, then make it dynamic with JavaScript.

  • ✓ HTML & semantic markup
  • ✓ CSS & responsive design
  • ✓ JavaScript fundamentals
  • ✓ React or Vue
  • ✓ Version control with Git

Back-end developer

Build the logic, databases, and APIs that power web applications from the server side.

  • ○ Python or Node.js basics
  • ○ SQL & database design
  • ○ REST API design
  • ○ Authentication & security
  • ○ Deployment & cloud basics

Data analyst

Use SQL and Python to collect, clean, and communicate data-driven insights.

  • ○ SQL fundamentals
  • ○ Python with pandas
  • ○ Data visualization
  • ○ Statistics basics
  • ○ Jupyter notebooks

Full-stack developer

Handle everything from the browser to the server. A broader role that combines front-end and back-end skills.

  • ○ HTML, CSS, JavaScript
  • ○ React + Node.js
  • ○ SQL & NoSQL databases
  • ○ REST & GraphQL APIs
  • ○ DevOps fundamentals
